This patch fixes the portable startup crash reported in #15 and #16 and repairs
the MSIX installer build and dependency packaging.

## Fixes

- Include the generated `WSAppBak.pri` in portable releases so compiled XAML
  resources are available when the app starts.
- Include the .NET runtime in both distributions.
- Correct and track the x64/ARM64 publish profiles; avoid the ARM64 ReadyToRun
  compiler crash and handle missing architecture information in build hosts.
- Ship the MSIX framework dependencies, a matching public signing certificate,
  and an installer script that selects the correct architecture.
- Add CI checks for the extracted portable ZIP and both MSIX architectures.

## Downloads and installation

- **Portable - x64 ZIP:** extract the whole ZIP and run `WSAppBak.exe`. Keep all
  extracted files together; copying only the executable will not work.
- **x64-ARM64 installer ZIP:** extract the whole ZIP, follow its certificate
  installation instructions, then run `Install.ps1` as your normal Windows user.
  It installs the bundle and its included dependencies together.
- **SHA256SUMS.txt:** SHA-256 checksums for both ZIP files.

The installer version is **2.0.1.0**. The portable application version is **2.0.1**.

## Validation and scope

The packaging fixes were tested with an offline Windows 11 Insider Sandbox:
MSIX installation, application startup and Help rendered successfully. A rebuilt
portable ZIP also passed its extracted-artifact launch test. ARM64 packages were
built and their contents checked; runtime testing on ARM64 hardware, Windows 10,
and stable Windows 11 remains outstanding.

This patch addresses packaging and startup. It does not resolve the separate
exported-package installation issue #13.
